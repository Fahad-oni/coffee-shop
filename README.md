# ☕ ONi's Cafe — Coffee Shop

A clean and responsive coffee shop landing page built with **HTML5 and CSS3**.

The project focuses on creating a warm, modern café experience through structured layouts, responsive design, custom styling, and visually engaging sections.

## 🌐 Live Demo

🔗 **[View Live Website](https://fahad-oni.github.io/coffee-shop/)**

## 📸 Overview

ONi's Cafe is a static coffee shop website featuring:

* 🏠 Hero / landing section
* 📖 About / story section
* ☕ Popular coffee menu
* 💰 Product pricing cards
* 🧭 Navigation bar
* 📱 Responsive layout
* 🎨 Custom café-inspired visual design

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Google Fonts**
* **Responsive Web Design**

## ✨ Key Features

### Hero Section

Introduces the café with a clear headline, description, and call-to-action.

### Our Story

A dedicated section presenting the story and identity of the café.

### Popular Picks

Displays popular coffee items with images, descriptions, and prices.

### Responsive Design

The layout is styled to adapt across different screen sizes.
